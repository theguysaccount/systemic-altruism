# Sources, foundations and rights

This project contains original code and original brief factual annotations with links. No upstream software was vendored in v0.1. We researched actual open-source implementations before choosing a minimal static foundation.

- [GivingTuesday Form 990 XML mapper](https://github.com/Giving-Tuesday/form-990-xml-mapper): actual MIT license (CitizenAudit/GivingTuesday, 2024). A useful future IRS-schema mapping foundation. Preserve its license if importing code.
- [RPublica](https://github.com/rOpenGov/RPublica): GPL-2 API-client implementation, researched as an adapter pattern. No code copied into this MIT project.
- [CharityLens](https://github.com/matthewgall/charitylens): UK registry explorer, README declares OGLv3 but no root license verified. Architecture researched; no code or database copied.
- [IRS Exempt Organization Business Master File](https://www.irs.gov/charities-non-profits/exempt-organizations-business-master-file-extract-eo-bmf) and [bulk Form 990 downloads](https://www.irs.gov/charities-non-profits/tax-exempt-organization-search-bulk-data-downloads): public registry sources for a future dated entity registry. Legal identity and filings are not impact ratings.
- [ProPublica Nonprofit Explorer API](https://projects.propublica.org/nonprofits/api): local live lookup only, with attribution and direct links. [Data terms](https://projects.propublica.org/datastore/terms/) restrict standalone raw-data redistribution. The adapter does not add raw results to the public corpus.
- [GiveWell](https://www.givewell.org/charities/top-charities): research content has CC BY-NC-SA 3.0 US terms. We link to current or historical program reviews and write original brief factual summaries; no report text is republished under our license.
- [Giving Green](https://www.givinggreen.earth/top-climate-nonprofits) and [Animal Charity Evaluators](https://animalcharityevaluators.org/recommended-charities/): referenced current recommendation lists and reviews. External recommendation labels describe source scope, never endorsement of our scores. No logos, badges, protected report text or evaluator dataset copied.
- [Charity Navigator API terms](https://developer.charitynavigator.org/termsofuse): competing evaluation services and redistribution prohibited as of the reviewed October 2, 2026 terms. Not integrated. Related public repositories lacked a verified license and were not copied.
- Google Fonts: optional hosted DM Sans and Manrope font styles. No font binary is distributed in this repository. The website's about page discloses external font requests.

Each data record retains URLs and review dates. Our licenses apply only to our original contributions; linked third-party material retains separate rights. No affiliation, sponsorship or endorsement is implied.
